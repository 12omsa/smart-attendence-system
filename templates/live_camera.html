How it works

  1. Click Start Camera.
  2. The system opens the connected webcam.
  3. AI detects the face.
  4. Passive anti-spoofing checks whether the detected face is a real person.
  5. If the face is live, InsightFace compares it with registered students.
  6. The identity must be confirmed across multiple frames.
  7. Only a verified live registered student can receive attendance.

Security Results

  • 🟢 Real registered student → Attendance can be marked.
  • 🔴 Photo → Access denied.
  • 🔴 Recorded face video → Access denied.
  • 🟠 Unknown live person → No attendance.
